## 共享总线与四态信号

在原有组合逻辑基础上，新增“共享总线实验”，使用带使能端的三态缓冲器（TRI）
让多个发送端轮流驱动同一根线。

- 信号区分四种状态：高电平 `1`、低电平 `0`、未确定/竞争 `X`、高阻 `Z`。
- 没有任何有效驱动的网络为高阻 `Z`；高阻不是低电平，目标检测不会把 `Z` 当作 0 通过。
- 两个有效驱动输出相反电平时判为竞争 `X`，冲突提示定位到实际参与的发送端，并随开关/使能变化自动出现或消失。
- 使能未知时，该发送端可能接通也可能断开，总线结果按 `X` 处理并提示对应发送端。
- 只有明确的**汇接点（JUNCTION）**或 BUS 内部短接才会合并电气网络；线路交叉不电气相连。
- 删除某个分支接收端或汇接点，只移除对应线段，不会断掉同一网络上的其他接收端。
- 普通逻辑门输入仍为单线；BUS 输入端口与汇接点支持多路汇入。
- 总线实验保存重开后保留汇接关系；各段连线的网络归属由拓扑确定性重建，信号归属一致。

顶部“总线示例”可一键载入两个三态发送端共享一条总线、多个探针分支读取的完整实验。
